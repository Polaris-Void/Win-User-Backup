# ابزار هوشمند پشتیبان‌گیری از پوشه‌های کاربری ویندوز

یک ابزار سبک، سریع و خودکار بر پایه بچ‌اسکریپت (Batch Script) در ویندوز جهت تهیه نسخه پشتیبان کامل از پوشه‌های اصلی کاربر (دسکتاپ، دانلودها، اسناد، تصاویر، موزیک و ویدیوها) با استفاده از موتور پرقدرت **Robocopy**.

برخلاف اسکریپت‌های ساده که فقط مسیرهای پیش‌فرض را کپی می‌کنند، این ابزار با بررسی رجیستری ویندوز (`User Shell Folders`)، حتی در صورت جابه‌جا شدن پوشه‌ها به درایوهای دیگر یا همگام‌سازی آن‌ها با **OneDrive**، مسیر واقعی فایل‌ها را شناسایی کرده و بدون جا انداختن اطلاعات از آن‌ها بکاپ می‌گیرد.

---

## ✨ قابلیت‌ها و ویژگی‌ها

* 🔑 **دریافت خودکار دسترسی ادمین (UAC):** بررسی سطح دسترسی با `net session` و باز کردن خودکار پنجره تأیید ادمین از طریق پاورشل.
* 🧠 **مسیریابی هوشمند از طریق رجیستری:** خواندن مسیرهای اختصاصی از کلید رجیستری `User Shell Folders` برای پیدا کردن پوشه‌هایی که توسط کاربر به درایوهای دیگر انتقال یافته‌اند.
* ☁️ **پشتیبانی کامل از OneDrive:** شناسایی خودکار پوشه‌های متصل به وان‌درایو در صورتی که پوشه‌های اصلی به فضای ابری منتقل شده باشند.
* ⚡ **موتور پشتیبان‌گیری پرسرعت Robocopy:** بهره‌گیری از سوئیچ‌های `/COPY:DAT` و `/DCOPY:DAT` برای کپی بدون نقص فایل‌ها همراه با متادیتا، ویژگی‌ها (Attributes) و تاریخچه‌های زمانی.
* 🛡️ **جلوگیری از حلقه‌های تکرار و بی‌نهایت:** استفاده از سوئیچ `/XJ` برای رد کردن لینک‌های سیستمی (Junction Points) و جلوگیری از ایجاد لوپ‌های تودرتوی بی‌پایان.
* ⏳ **مدیریت هوشمند فایل‌های قفل‌شده:** استفاده از تنظیمات `/R:1 /W:1` تا در صورت قفل بودن یک فایل موقت، کل فرایند متوقف نشود.
* 📦 **کاملاً پرتابل:** ایجاد پوشه پشتیبان با نام `Windows Backup` دقیقاً در کنار محل قرارگیری اسکریپت (بسیار مناسب جهت اجرا مستقیم از روی فلش‌مموری یا هارد اکسترنال).

## 📂 پوشه‌های تحت پوشش

| نام پوشه | شناسه رجیستری ویندوز |
| :--- | :--- |
| **دسکتاپ (Desktop)** | `Desktop` |
| **دانلودها (Downloads)** | `{374DE290-123F-4565-9164-39C4925E467B}` |
| **اسناد (Documents)** | `Personal` |
| **موزیک (Music)** | `My Music` |
| **عکس‌ها (Pictures)** | `My Pictures` |
| **ویدیوها (Videos)** | `My Video` |

## 🚀 راهنمای استفاده

1. اسکریپت را با پسوند **`.bat`** ذخیره کنید (مثلاً `Windows-Backup.bat`).
2. فایل را در محلی که می‌خواهید بکاپ در آن ذخیره شود قرار دهید (مثلاً درون هارد اکسترنال یا یک پارتیشن دیگر).
3. روی فایل **دو بار کلیک** کنید.
4. در صورت درخواست، پنجره دسترسی **UAC** را تأیید کنید.
5. فرایند کپی آغاز شده و پوشه‌ای با نام **`Windows Backup`** در کنار فایل اسکریپت ایجاد می‌شود.
6. اسکریپت وضعیت اتمام عملیات را گزارش داده و پس از ۱۰ ثانیه به طور خودکار بسته می‌شود.

## 💻 پیش‌نیازهای سیستم

* **سیستم‌عامل:** ویندوز 7، 8.1، 10 یا 11.
* **پاورشل (PowerShell):** جهت ارتقای خودکار سطح دسترسی.
* **سطح دسترسی:** ادمین (اسکریپت به صورت خودکار آن را درخواست می‌کند).
