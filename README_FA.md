# ابزار پشتیبان‌گیری و بازیابی پوشه‌های کاربری ویندوز

مجموعه‌ای سریع، سبک و خودکار از دو اسکریپت Batch برای ویندوز. فایل **`Backup.bat`** پوشه‌های اصلی کاربر (Desktop، Downloads، Documents، Pictures، Music و Videos) را با موتور پرسرعت **Robocopy** در مسیر `C:\User Backup` پشتیبان‌گیری می‌کند و فایل **`Restore.bat`** آن‌ها را بدون بازنویسی یا حذف هیچ فایلی به پروفایل شما برمی‌گرداند.

برخلاف اسکریپت‌های ساده‌ای که فقط به مسیرهای ثابت تکیه می‌کنند، این ابزار مسیر واقعی پوشه‌ها را به‌صورت پویا از رجیستری ویندوز (`User Shell Folders`) می‌خواند تا پوشه‌های جابه‌جا‌شده، درایوهای تغییرمسیر‌داده‌شده و پوشه‌های همگام‌شده با Microsoft OneDrive را نیز تشخیص دهد.

---

## ✨ ویژگی‌ها

### 📥 Backup.bat

- **🔑 ارتقای خودکار دسترسی (UAC):** در صورت نیاز، اسکریپت خودش را از طریق PowerShell (با `RunAs`) با دسترسی Administrator دوباره اجرا می‌کند. یک پرچم محافظ هم از ایجاد حلقه‌ی بی‌پایان در صورت ناموفق بودن ارتقا جلوگیری می‌کند.
- **🧠 تشخیص پویا از رجیستری:** مسیر واقعی پوشه‌ها را از `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders` می‌خواند. نام مقدارهایی که فاصله دارند (`My Music`، `My Pictures` و `My Video`) درست پردازش می‌شوند و متغیرهایی مثل `%USERPROFILE%` به مسیر کامل تبدیل می‌شوند.
- **☁️ زنجیره‌ی جایگزین هوشمند:** مسیر رجیستری ← پوشه‌ی استاندارد پروفایل ← پوشه‌های همگام‌شده‌ی OneDrive (`%OneDrive%`، `%OneDriveConsumer%`، `%OneDriveCommercial%` و `%USERPROFILE%\OneDrive`).
- **⚡ موتور قدرتمند Robocopy:** با پرچم‌های `/E /COPY:DAT /DCOPY:DAT` فایل‌ها، ساختار پوشه‌ها، ویژگی‌ها (Attributes) و زمان‌ها حفظ می‌شوند. در اجراهای بعدی فقط فایل‌های جدید یا تغییرکرده کپی می‌شوند.
- **🛡️ ایمنی در برابر حلقه و Junction:** نقاط اتصال (`/XJ`) و خود پوشه‌ی پشتیبان (`/XD "C:\User Backup"`) از کپی مستثنا می‌شوند.
- **⏳ تلاش مجدد سریع:** با `/R:1 /W:1` فایل‌های قفل‌شده به‌جای گیر انداختن پشتیبان‌گیری، رد می‌شوند.
- **🚫 بدون هیچ فایل لاگ:** هیچ فایل `.log` ساخته نمی‌شود و خروجی Robocopy کاملاً بی‌صدا است. هر فایل `*.log` موجود در سطح اصلی `C:\User Backup` هنگام شروع پاک می‌شود (زیرپوشه‌ها دست‌نخورده می‌مانند؛ پس فایل‌های لاگ خودتان که در پشتیبان قرار دارند حذف نمی‌شوند).
- **🎨 کنسول تمیز و بدون سوسو:** تم فیروزه‌ای، سرآیند قاب‌دار و یک خط وضعیت زنده با نقطه‌چین برای هر پوشه.
- **⏱️ شمارش معکوس بدون قفل شدن:** شمارش معکوس ۱۰ ثانیه‌ای (`10..1`) در همان یک خط، که با فشردن هر کلید بلافاصله تمام می‌شود و در کنسول‌های Elevated یا Redirect شده هم متوقف نمی‌شود.

### 📤 Restore.bat

- **✅ پرسش تأیید:** تا وقتی `Y` نزنید هیچ اتفاقی نمی‌افتد. با `N` عملیات لغو می‌شود.
- **🧩 ادغام غیرتخریبی:** فقط فایل‌هایی که در پروفایل شما وجود ندارند بازگردانی می‌شوند. هیچ فایل موجودی بازنویسی یا حذف نمی‌شود (`/XC /XN /XO` و بدون `/MIR` یا `/PURGE`).
- **🎯 مقصد هوشمند:** از همان روش رجیستری ← پروفایل ← OneDrive استفاده می‌کند تا فایل‌ها در پوشه‌هایی که ویندوز واقعاً به کار می‌برد قرار بگیرند. اگر پوشه‌ای هنوز وجود نداشته باشد، ساخته می‌شود.
- **⏭️ عبور امن از موارد ناموجود:** پوشه‌هایی که در پشتیبان نیستند با وضعیت `SKIP` رد می‌شوند.
- **🔒 پشتیبان دست‌نخورده:** `C:\User Backup` فقط خوانده می‌شود و هرگز تغییر نمی‌کند.
- **🎨 ظاهر یکسان:** سرآیند، خط‌های وضعیت و شمارش معکوس دقیقاً مثل `Backup.bat` است.

## 🚀 نحوه‌ی استفاده

### پشتیبان‌گیری (Backup)

1. فایل‌های `Backup.bat` و `Restore.bat` را دانلود کنید و در هر جایی که می‌خواهید (مثلاً Desktop) ذخیره کنید.
2. روی `Backup.bat` **دوبار کلیک** کنید.
3. در پنجره‌ی **UAC** درخواست دسترسی Administrator را تأیید کنید.
4. وضعیت زنده‌ی هر پوشه را ببینید. همه‌ی اطلاعات در **`C:\User Backup`** کپی می‌شود.
5. پنجره پس از ۱۰ ثانیه یا با فشردن هر کلید بسته می‌شود.

### بازیابی (Restore)

1. اگر ویندوز را تازه نصب کرده‌اید یا روی رایانه‌ی دیگری کار می‌کنید، ابتدا پشتیبان را طوری کپی کنید که در مسیر **`C:\User Backup`** قرار بگیرد.
2. روی `Restore.bat` **دوبار کلیک** کنید و پنجره‌ی **UAC** را تأیید کنید.
3. برای تأیید بازیابی کلید **`Y`** را بزنید (یا با `N` لغو کنید).
4. فایل‌های ناموجود به پوشه‌های پروفایل شما اضافه می‌شوند. پنجره پس از ۱۰ ثانیه یا با فشردن هر کلید بسته می‌شود.

```text
+============================================================+
|                    USER PROFILE BACKUP                     |
+============================================================+

Target Path  : C:\User Backup
User Profile : C:\Users\YourName

[+] Desktop ....................................... [  DONE  ]
[+] Downloads ..................................... [  DONE  ]
[+] Documents ..................................... [  DONE  ]
[+] Music ......................................... [  DONE  ]
[+] Pictures ...................................... [  DONE  ]

Closing in  7 s ...  press any key to exit
```

| وضعیت        | معنی                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| `[  DONE  ]` | پوشه با موفقیت پردازش شد.                                                                |
| `[  SKIP  ]` | پوشه‌ی مبدأ (در Backup) یا پوشه‌ی موجود در پشتیبان (در Restore) پیدا نشد.                |
| `[ FAILED ]` | Robocopy خطا گزارش کرد (مثلاً فایل‌هایی که پس از تلاش مجدد هنوز قفل بودند).              |

## ⚙️ شخصی‌سازی

- **تغییر محل پشتیبان:** خط `BackupRoot` را در بخش بالای **هر دو** اسکریپت ویرایش کنید (`set "BackupRoot=C:\User Backup"`).
- **جایگزینی فایل‌های قدیمی‌تر با نسخه‌ی جدیدتر پشتیبان هنگام بازیابی:** در `Restore.bat` عبارت `/XC /XN /XO` را با `/XO` عوض کنید. فایل‌های موجودی که از پشتیبان جدیدتر باشند همچنان حفظ می‌شوند.
- **پاک‌سازی بازگشتی لاگ‌ها:** در `Backup.bat` به فرمان `del` در خط پاک‌سازی لاگ، گزینه‌ی `/s` را اضافه کنید. توجه کنید که این کار فایل‌های `.log` مربوط به داده‌های پشتیبان‌گیری‌شده‌ی شما را هم پاک می‌کند.

## ⚠️ نکات و محدودیت‌ها

- پشتیبان به‌طور پیش‌فرض روی درایو سیستم ذخیره می‌شود. برای محافظت در برابر خرابی دیسک، پوشه‌ی `C:\User Backup` را روی هارد اکسترنال یا فضای ابری هم کپی کنید.
- پشتیبان‌گیری افزایشی است: فایل‌هایی که بعداً از پروفایل خود حذف می‌کنید، از `C:\User Backup` **پاک نمی‌شوند**.
- اگر قابلیت Files On-Demand در OneDrive فعال باشد، فایل‌های «فقط آنلاین» ممکن است هنگام کپی شدن دانلود شوند.
- اسکریپت‌ها را با حساب مدیر (Administrator) خودتان اجرا کنید. اگر UAC از طریق حساب دیگری ارتقا بدهد، `%USERPROFILE%` و رجیستری به همان حساب اشاره می‌کنند.
- فقط شش پوشه‌ی استاندارد پوشش داده می‌شود. `AppData`، پروفایل مرورگرها و برنامه‌های نصب‌شده جزو پشتیبان نیستند.

## 💻 پیش‌نیازهای سیستم

- **سیستم‌عامل:** Windows 7، Windows 8.1، Windows 10 یا Windows 11.
- **PowerShell:** برای ارتقای خودکار UAC و شمارش معکوس لازم است.
- **دسترسی:** دسترسی Administrator (به‌صورت خودکار درخواست می‌شود).
